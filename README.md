## About me
I build real-time robotics systems that combine Unity simulations with ROS, RTAB-Map SLAM, YOLO object detection, and a lightweight Flask dashboard. I love turning prototypes into reproducible engineering demos.

<img align="centre" src="https://user-images.githubusercontent.com/74038190/212284100-561aa473-3905-4a80-b561-0d28506553ee.gif" />

## Featured Projects
**LunaBot — Autonomous Rover Platform**  
Unity → ROS Noetic → RTAB-Map → YOLOv8 → Flask dashboard. Custom Unity→ROS transform bridge for REP-103 compatibility, depth → 3D semantic mapping, and a battery-aware backtracking mode.

**AI Resume Screening** — TF-IDF + Random Forest pipeline with skill extraction and ATS scoring.

**Portfolio Platform** — React + Flask, GitHub integration and demo video hosting.
